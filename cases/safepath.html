File No. III · SafePath
Case Closed

The Case of the Missing Signal

RoleSolo Build
Timeframe2024
InstrumentsJavaScript · Firebase · Google APIs · PWA

The Complaint

What Brought Me to the Case

The scenario that opened this case is the one every safety app claims to solve and few actually do: someone in an emergency needs real-time location tracking and a route to help, right now — not after downloading a heavy app and creating an account.

The client's requirement was speed and reliability: something offline-capable, installable in seconds, and able to route a person to nearby help without delay.

The Investigation

How the Case Was Solved

I architected SafePath as an offline-capable Progressive Web App, leveraging Firebase for real-time data and Google Maps and Geolocation APIs for live location tracking and emergency routing.

On top of that I designed an accessible one-tap alert system that rapidly identifies nearby help centers the moment it's triggered, so a user in distress doesn't have to search for anything.

Every part of the transmission path was built to be secure, lightweight, and immediate — offline capability included, so the core alert still fires even when connectivity briefly drops.

  • Offline-capable Progressive Web App built with Firebase
  • Google Maps and Geolocation APIs for real-time tracking and routing
  • One-tap alert system identifying nearby help centers
  • Secure, lightweight, immediate emergency data transmission

The Verdict

Closing the File

A lightweight, installable PWA that tracks a user's location in real time and routes them — and their alert — to nearby help the instant it's needed.
